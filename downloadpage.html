Windows SmartScreen and “Unknown publisher”

You may see a blue Windows protected your PC screen the first time you run the installer. That happens when Windows does not yet recognize the file or the app is not signed with a commercial code signing certificate. It does not mean the download is corrupt.

If you trust this download (you got it from this site or our official GitHub release):

  1. Click More info (if shown).
  2. Click Run anyway.

To show a verified publisher name and reduce SmartScreen warnings over time, we need to sign the installer with an Authenticode certificate from a trusted CA (and use a timestamp server when signing). That is a paid yearly certificate plus a one-time setup in your build pipeline (e.g. Inno Setup + signtool). Download page tweaks cannot remove this warning; signing the .exe does.
