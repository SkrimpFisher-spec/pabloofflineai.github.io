# Place your wedding photos here

| File | Used for |
|------|----------|
| `hero.jpg` | Full-screen hero background (landscape, 1920px+ wide recommended) |
| `story.jpg` | Our Story section (portrait, 800px+ wide) |
| `music.mp3` | Optional background music (off by default) |

After adding `hero.jpg`, the gradient placeholder is replaced automatically.
